# 세 모델 앙상블 결과

> 노트북: `ensemble.ipynb`
> 모델: ResNet18 + EfficientNet-B0 + ConvNeXt-Tiny

## 한 줄 결론

> **앙상블하면 성능이 오르긴 하지만 폭이 작습니다.**
> 추론 비용이 2~3배 늘어나는 것에 비해 이득이 작아서, 실무에서는 **EfficientNet-B0 단독으로도 충분합니다.**

---

## 1. 방법

- 이미 학습해 둔 체크포인트 3개를 불러와서 **각 모델의 예측 확률(softmax)을 평균**합니다. 이 방식을 soft voting이라고 합니다. **재학습은 없습니다.**
- 데이터 전처리와 분할(SEED=1414)은 개별 학습 노트북과 같습니다. test 세트도 같은 5,104장입니다.
- 모든 모델에 TTA(8방향 예측 평균)를 적용했습니다.
- **어떤 조합을 쓸지는 val 세트로 골랐습니다.** test로 고르면 성능이 실제보다 좋게 보이기 때문입니다.

---

## 2. 결과 (test 5,104장)

| 조합 | 정확도 | Macro F1 | 오분류 |
|---|---|---|---|
| ResNet18 단독 | 95.57% | 0.9392 | 226 |
| EfficientNet-B0 단독 | 95.49% | 0.9430 | 230 |
| ConvNeXt-Tiny 단독 | 95.77% | 0.9378 | 216 |
| R18 + EffB0 | 95.85% | **0.9495** | 212 |
| R18 + ConvNeXt | 95.77% | 0.9418 | 216 |
| **EffB0 + ConvNeXt** (val 기준 선택) | 95.87% | 0.9462 | 211 |
| 세 모델 전부 | **95.96%** | 0.9488 | **206** |

## 3. 클래스별 F1 (단독 모델 vs 앙상블 EffB0 + ConvNeXt)

| 클래스 | ResNet18 | EffB0 | ConvNeXt | **앙상블** |
|---|---|---|---|---|
| Center | 0.978 | 0.975 | 0.977 | 0.976 |
| Donut | 0.915 | 0.927 | 0.934 | **0.935** |
| Edge-Loc | 0.937 | 0.935 | 0.939 | **0.942** |
| Edge-Ring | 0.990 | 0.987 | 0.989 | 0.988 |
| Loc | 0.893 | 0.894 | 0.901 | **0.903** |
| Random | 0.935 | 0.933 | 0.931 | **0.943** |
| Scratch | 0.898 | 0.909 | 0.909 | **0.916** |
| Near-full | 0.968 | 0.983 | 0.921 | 0.968 |

---

## 4. 해석

### ① 좋아지긴 하지만 폭은 작다
단독 모델 중 가장 좋은 것과 비교하면 다음과 같습니다.
- 정확도: **+0.2~0.4%p** (10장 정도 덜 틀림)
- Macro F1: **+0.003~0.007**

### ② 조합은 val로 골랐다
- val 기준으로는 **EffB0 + ConvNeXt**가 선택됐습니다.
- test에서는 **세 모델 전부**가 조금 더 좋았지만, 둘의 차이는 5장이라 사실상 같은 수준입니다.

### ③ 약한 클래스가 조금씩 나아졌다
- Scratch: 0.909 → **0.916**
- Random: 0.935 → **0.943**
- Near-full: ConvNeXt 혼자일 때 0.921로 약했던 것을 EffB0가 보완해서 **0.968**로 돌아왔습니다.

### ④ 크게 오르지 않는 이유: 세 모델이 같은 샘플을 같이 틀린다

| 비교 | 둘 다 틀림 | 한쪽만 틀림 |
|---|---|---|
| R18 vs EffB0 | 161 | 134 |
| R18 vs ConvNeXt | 154 | 134 |
| EffB0 vs ConvNeXt | 153 | 140 |

- **세 모델 모두 틀린 샘플은 129장입니다.** 앙상블로는 고칠 수 없는 샘플들입니다.
- 모델 둘씩 비교해도 둘 다 틀린 샘플이 한쪽만 틀린 샘플보다 많습니다.
- 학습 데이터와 학습 방식이 같아서 **비슷한 실수를 하기 때문**입니다. 앙상블은 모델들이 서로 다르게 틀릴 때 효과가 큽니다.

---

## 5. 결론 및 다음 단계

- **실무 관점:** 추론 비용 2~3배에 비해 이득이 작으므로, **EfficientNet-B0 단독**으로 충분합니다.
- **성능을 더 올리려면:** 모델 수를 늘리기보다 **세 모델이 공통으로 틀린 129장을 직접 확인**하는 게 다음 단계입니다.
  - 사람이 봐도 애매해서 라벨이 모호한 샘플인지
  - 96px 해상도가 부족해서 패턴이 뭉개진 것인지 (그렇다면 128px로 다시 학습)
