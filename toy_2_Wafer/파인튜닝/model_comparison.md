# 웨이퍼 결함 패턴 분류 — 3가지 모델 비교

## 한 줄 결론

> **세 모델 모두 정확도 약 95.5~95.8%로 사실상 같은 성능입니다.
> 가장 작고 빠르면서 클래스 간 성능이 고른 EfficientNet-B0를 추천합니다.**

---

## 1. 실험 조건 (공정한 비교를 위해 모두 동일)

| 항목 | 설정 |
|---|---|
| 데이터 | `wb_withpattern.pkl`, 패턴이 있는 웨이퍼 25,519장, 8개 클래스 |
| 분할 | train 72% / val 8% / test 20% (test 5,104장, SEED=1414로 고정) |
| 입력 | 96×96, 픽셀값 0/128/255로 변환 |
| 증강 | 90° 회전 + 좌우 반전 (8가지) |
| 학습 | 최대 30 epoch, val macro F1이 7 epoch 동안 안 오르면 중단 |
| 평가 | TTA 적용 (8방향 예측을 평균) |

**바꾼 것은 백본(모델 구조) 하나뿐입니다.**

---

## 2. 종합 성능표 (test 세트 5,104장)

| 모델 | 크기 (파라미터) | 정확도 | Macro F1 | 틀린 개수 | 한 줄 평 |
|---|---|---|---|---|---|
| ResNet18 (기준) | 11.2M (중간) | 95.6% | 0.939 | 약 226 | 무난한 기준 모델 |
| **EfficientNet-B0** | **4.0M (가장 작음)** | 95.5% | **0.943 🥇** | 230 | 작고 빠르고 고른 성능 |
| ConvNeXt-Tiny | 27.8M (가장 큼) | **95.8% 🥇** | 0.938 | **216** | 전체적으로 가장 많이 맞히지만, 희귀 클래스 하나에서 약함 |

> ResNet18의 틀린 개수는 정확도로 역산한 값입니다.


**용어 풀이**
- **정확도:** 전체 중에 맞힌 비율입니다. 데이터가 많은 클래스(Edge-Ring 등)를 잘 맞히면 높게 나옵니다.
- **Macro F1:** 8개 클래스 각각의 점수(F1)를 **똑같은 비중으로** 평균 낸 값입니다. 희귀 클래스(Near-full 30장, Donut 111장)도 큰 클래스와 같은 무게로 반영됩니다. **불균형 데이터에서는 이 지표가 더 중요합니다.**

## 4. 결론

1. **성능 차이는 거의 없습니다.**
   정확도 차이는 최대 0.3%p(약 14장), Macro F1 차이는 0.005입니다. test 분할을 하나만 써서 나온 결과라, 이 정도는 우연으로도 생길 수 있는 차이입니다.

2. **추천: EfficientNet-B0**
   - 파라미터가 ResNet18의 약 1/3, ConvNeXt-Tiny의 약 1/7입니다. 학습과 추론이 빠르고, 저장 용량도 작습니다.
   - Macro F1이 가장 높습니다. 희귀 클래스까지 고르게 잘 맞힌다는 뜻입니다.

3. **ConvNeXt-Tiny는 "전체 정답 수"가 중요할 때 고려할 만합니다.**
   틀린 개수가 가장 적습니다. 다만 모델이 가장 크고 느리며, Near-full에서 점수가 낮습니다.

4. **모델을 바꿔도 안 풀리는 공통 약점: Loc, Scratch**
   세 모델 모두 이 두 클래스가 F1 약 0.89~0.91로 가장 낮고, 주로 Edge-Loc과 헷갈립니다. 백본을 바꿔서는 해결되지 않는 문제입니다.

## 5. 다음에 해볼 만한 것

| 방법 | 기대 효과 |
|---|---|
| 해상도 올리기 (96 → 128) | 작은 Loc 점이나 얇은 Scratch 선이 덜 뭉개짐 |
| 세 모델 앙상블 (확률 평균) | 모델마다 잘하는 클래스가 달라서, 합치면 서로 보완 |
| 여러 seed로 반복 실험 | 이번 차이가 진짜 차이인지 우연인지 확인 |
